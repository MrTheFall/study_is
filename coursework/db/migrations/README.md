# DB migrations

Для изменений схемы/функций без пересоздания базы используйте версионированные миграции:

- Кладите SQL‑файлы в `db/migrations/` (например, `001_add_column_x.sql`, `002_fix_function_y.sql`).
- Запускайте `./scripts/migrate_db.sh` — скрипт применит все новые миграции по имени файла (лексикографически) и запишет их в таблицу `schema_migrations`.
- Уже применённые файлы нельзя редактировать: скрипт проверяет `sha256` и упадёт при несовпадении.

Примечание: `db/schema.sql` и `db/functions.sql` остаются “снимком” актуального состояния для чистого развёртывания (`./scripts/create_db.sh`).
